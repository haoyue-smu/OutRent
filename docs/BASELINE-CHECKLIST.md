# Baseline checklist · OutRent Iter2 (24 Oct; sections used by the review)

Every item is yes / no. Report only a "no", as: item number · page/state · one line.

## A · Facts
1. Every number, time, date, name and ID on the page matches MOCK-DATA: S$50 all-in, S$38 / day, S$12 delivery, S$150 deposit, 7:40 delivery, 13:30 collection, 25 Oct, OR-10482, Trek Marlin 7 · size M, Timah Cycles, saddle 72 cm, frame M, S$45 weekly (check the current MOCK-DATA for the rest).
2. The frame shows the right state for its place in the demo route (first-time renter: no past trips; a "choosing" state shows nothing chosen; after booking, the booked values appear).
3. Nothing on the page is invented: every value either exists in MOCK-DATA or is a labelled placeholder.

## B · Words
4. No text breaks badly at 393 px: no word split across lines, no one-word last line, no cut-off string, no text squeezed into a narrow column beside an icon.
5. No jargon a first-time renter cannot read; no explanatory padding to rescue a bad layout.
6. Dates and times in the house form "25 Oct · 7:40"; two records side by side use the same form; the same thing is called the same word everywhere (Bookings, collection, hand-over, deposit).

## C · Buttons and exits
7. Every button and link says where it goes; nothing repeats what the page already shows.
8. One exit per screen (back or close, not both); back goes where Daniel came from.
9. Exactly one primary action per screen, and it is the obvious one.

## D · Layout integrity
10. Nothing overlaps, touches or is clipped (controls have room; cards hold their own content; the action bar does not cover content).
11. Things that describe the same object are in the same card; no stray element outside its card.
12. No area taller than about a third of the screen with nothing in it, and nothing stretched or enlarged only to fill space.

## F · Consistency across pages (once, over all pages)
20. The same component looks the same on every page: top bar, cards, chips, segmented control, action bar, tab bar.
21. The money pages (05, 07, 08, 12) each read as their own job (worth it · what I pay · proof · how it ended), and the deposit is treated the same quiet way on all four.
22. The app reads as one app from 01 to 18: same spacing rhythm, same card radius, same title size, same button height.
