# OutRent wording rules (Haoyue, 23 Oct 2026)

Every string in the app follows these. Check each screen against them before it ships.

1. **Say when it happens.** A label must be true at the moment it is shown. Before delivery: "Adjusted for you before delivery" / "Timah Cycles will adjust it on Friday evening". Only after: "Adjusted on Fri, 7:15 pm". Never "Ready" or "Set up" for something that has not happened yet.
2. **The app never speaks as "we".** No "We remind you", "We only show bikes that fit you". Use neutral statements ("You'll get a reminder on Friday evening") or plain labels.
3. **No instructions in conversation tone.** No "Drag the ruler", "Tap here to…". Controls explain themselves.
4. **Labels over sentences.** A field label, a value, a short helper line. One idea per line.
5. **Every fact has a visible source** when it is not obvious: "From Coach Aisyah's ride", "From your height (176 cm)", "Photos from Timah Cycles, Wed 22 Oct".
6. **No jargon.** No "hardtail", no "fork sag". Say what it does for the rider: "Saddle height", "Handlebar height". (PO: "hardtail" may stay inside the coach's quoted note because it is her voice.)
7. **Buttons name the result.** "Choose delivery", "Pay S$53", "Book Coach Aisyah's next ride"; never "Continue" or "Repeat".
8. **Money says what it is and when.** "Paid", "Held, not charged", "Released in 3–5 working days after the return check".

House rules added later:
- Dates are written "25 Oct · 7:40" (short date, then time) everywhere; two records shown side by side use the same form (Haoyue, 24 Oct).
- Examples above predate the mock data; where a value differs, MOCK-DATA wins.
- Dialogs: the option to stay goes on top, the leaving/destructive option at the bottom; equal weight, told apart by text colour only (Haoyue, 23 Oct).
